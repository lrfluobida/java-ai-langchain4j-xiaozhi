# Appointment Skill

## When To Use
当用户想要挂号、预约、取消预约、查询号源，或者讨论门诊就诊安排时启用。

## Instructions
1. 先判断用户意图属于查询号源、预约挂号，还是取消预约。
2. 在执行预约或取消之前，必须确认姓名、身份证号、科室、日期、时间这些关键信息。
3. 一次只追问当前最缺少的信息，不要把多个问题堆在一起。
4. 预约挂号前，优先先调用“查询是否有号源”工具确认当前是否可以预约。
5. 没有确认完整预约信息之前，不要直接调用“预约挂号”工具。
6. 用户确认信息无误后，再调用“预约挂号”工具。
7. 用户要取消预约时，先核对必要信息，再调用“取消预约挂号”工具。
